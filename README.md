# Kartografia Zmysłów — Android Edition

A consent-first, private, two-player sensory strategy game adapted from the original analog design.

## Product direction
- Android-first mobile/PWA architecture with offline-capable game state.
- Strategic core: calibration → bag-building → engine-building → push-your-luck → resolution/aftercare.
- Mobile translation: no explicit sexual content is rendered or narrated by the app. Physical actions remain private, player-directed choices.
- Safety is a hard system constraint: pause, stop, revoke/modify boundaries, and session exit are always one gesture away.
- Local-first data model: session state is kept on-device unless a future sync layer is explicitly added.

## Repository
The repository contains the product specification, data model, game engine contract, UX system, Android packaging plan, accessibility requirements, QA strategy, and implementation seed files.
